# GemSpot Project Plan

## Product Direction

GemSpot should feel more like a creative portal than a store. The focus is free indie games, experiments, prototypes, reviews, and community discovery.

## Target Users

- indie game creators
- beginner developers
- players looking for small or unusual free games
- reviewers/testers who want to give useful feedback

## MVP Features

1. Accounts
2. Creator profiles
3. Project pages
4. Upload/download support
5. Browser-playable game support
6. Tags and search
7. Ratings
8. Structured reviews
9. Comments
10. Admin moderation

## Phase Two Ideas

- creator credits and collaborator roles
- game jams
- collections/playlists
- medal or achievement system
- playtest rooms
- version-based reviews
- hidden gem discovery section
- reviewer reputation
- devlogs and changelogs

## First Build Goal

The first real milestone should be:

> A creator can create a project page, upload a free game, and a visitor can find it, view it, and leave feedback.
